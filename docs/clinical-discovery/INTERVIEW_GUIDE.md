# Guia de entrevistas — Sprint 0

O banco completo de temas existe para **várias** conversas. A primeira reunião usa só o roteiro curto abaixo.

## Primeira conversa (30–45 minutos)

**Objetivo:** sair com um candidato a MVP 1 e com pedido de material, não com Doppler resolvido.

**Quem:** Dra. Karen. Facilitação: produto. Engenharia pode ouvir; não debate arquitetura na mesa dela.

**Abertura (2 min):** o evolUSG vai nascer na rotina obstétrica dela; hoje queremos entender o trabalho real; nada será inventado sem ela.

### Roteiro (usar nesta ordem)

1. **Quais exames obstétricos você realiza hoje?**  
   Listar nos termos dela. Não oferecer uma taxonomia pronta no início. Depois, só se faltar: 1º trimestre, morfológico, vitalidade, Doppler, colo, gemelar, outros.

2. **Desses, quais são os mais frequentes na semana?**  
   Alta / média / baixa. Qual é o “exame do dia a dia”?

3. **Se o evolUSG só pudesse fazer um tipo de exame muito bem no começo, qual deveria ser?**  
   Por quê? (volume, dor, tempo, risco de erro)

4. **Como é o fluxo hoje no Turing, desse exame?**  
   Da paciente na sala até o papel/PDF na mão. Onde copia exame anterior? Onde trava?

5. **Onde você mais perde tempo?**  
   Top 3, sem filtro. Cliques, frases, busca de paciente, impressora, campos obrigatórios inúteis, gemelar, etc.

6. **O que o Turing faz que o evolUSG não pode piorar?**  
   Indispensáveis.

7. **O que mais incomoda ou você contorna no Turing?**  
   Limitações concretas.

8. **Como você estrutura o laudo?**  
   Ordem mental de preenchimento. O que vai para conclusão vs corpo. O que nunca falta.

9. **Quais frases são “suas” — jeito pessoal de escrever?**  
   Um ou dois exemplos bastam agora (ex.: “feto” vs outra palavra). Não catalogar o universo.

10. **O que podemos levar hoje, anonimizado?**  
    Template do exame mais usado; 2–5 laudos desse tipo sem nome/identificadores; se fácil, um exemplo de documento emitido com dados fictícios.

**Encerramento (2 min):** repetir o candidato a primeiro exame; confirmar o que ela vai enviar; marcar se precisa de segunda conversa só de laudo.

### O que não perguntar nesta reunião

Doppler vaso a vaso, tabelas de percentil, fórmulas, trigemelar, ICP-Brasil, campos raros, LGPD jurídica, stack.

## Banco de temas (reuniões posteriores)

Usar **um bloco por sessão**, não todos de uma vez.

| Código | Tema | Quando |
|---|---|---|
| A | Rotina de atendimento (volume, sala vs depois, computadores) | Onda 1 se sobrar tempo; senão depois |
| B | Tipos obstétricos (detalhar o inventário) | Onda 1 e 2 |
| C | Estrutura dos laudos | Onda 2 |
| D–E | Obrigatórios vs opcionais | Onda 2 |
| F–G | Achados frequentes e raros | Onda 2–3 |
| H | Biometria | Sessão específica |
| I | Doppler | Sessão específica |
| J | Cálculos e fontes | Sessão específica; nenhum cálculo sem ela |
| K | Conclusões | Onda 2–3 |
| L | Fraseologia pessoal | Onda 3 |
| M | Casos especiais | Depois do MVP 1 recortado |
| N | Gemelares | Se houver volume |
| O | Comparação com exames anteriores | Antes da sprint de histórico |
| P | Correção / retificação de laudos | Onda 5 / documentos |
| Q | Assinatura e impressão | Antes da sprint de documentos |
| R–V | Turing: fluxo, keep, drop, desejos | Onda 1 (alto nível) e Onda 3 (detalhe) |

Perguntas detalhadas desses blocos podem ser acrescentadas nas atas. Não copiar um questionário de 20 grupos para a primeira mesa.

## Registro

Após cada conversa: ata curta + itens `PENDING CLINICAL DISCOVERY` + classificação de feedback se ela já opinar sobre o produto (ainda não há produto).
